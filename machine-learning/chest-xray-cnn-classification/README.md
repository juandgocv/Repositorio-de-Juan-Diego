# Chest X-Ray Classification with CNN

**Tools:** Python · TensorFlow/Keras · OpenCV · Matplotlib  
**Topic:** Computer Vision · Deep Learning · Medical Imaging

## Overview

A convolutional neural network (CNN) trained to automatically classify chest X-ray images into three categories: **Normal**, **Pneumonia**, and **COVID-19**. The project addresses the challenge of subjective clinical interpretation and specialist bottlenecks in high-demand healthcare settings.

## What's Inside

| `chest-xray-cnn-classification.ipynb` | Full pipeline: EDA → preprocessing → CNN architecture → training → evaluation |
