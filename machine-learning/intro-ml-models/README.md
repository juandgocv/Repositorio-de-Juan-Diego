# Intro to ML Models: MLP, Random Forest & SVM

**Tools:** RapidMiner  
**Topic:** Supervised Learning · Model Comparison · AI Fundamentals

## Overview

A comparative study of three classical machine learning models — **Multi-Layer Perceptron (MLP)**, **Random Forest**, and **Support Vector Machine (SVM)** — built and evaluated in RapidMiner as part of an Introduction to Artificial Intelligence course.

## What's Inside

| File | Description |
|------|-------------|
| `mlp-model.rmp` | Multi-Layer Perceptron model process |
| `random-forest-model.rmp` | Random Forest model process |
| `svm-model.rmp` | Support Vector Machine model process |
| `ml-models-comparison-presentation.pptx` | Presentation with methodology, results, and model comparison |
