# Credit Card Uptake Prediction — kNN & Logistic Regression

**Tools:** Python · scikit-learn · Pandas · Seaborn  
**Topic:** Binary Classification · Model Comparison · Banking Analytics

## Overview

Predicts whether a bank customer will acquire a credit card using the Universal Bank dataset. Two models are implemented and compared: **k-Nearest Neighbors (kNN)** and **Logistic Regression**, with hyperparameter tuning and full evaluation.

## What's Inside

| File | Description |
|------|-------------|
| `credit-card-uptake-prediction.ipynb` | EDA → preprocessing → kNN → Logistic Regression → comparison |
| `dataset.xlsx` | Universal Bank dataset with customer demographics and financial profile |

## Highlights

- Feature engineering and exploratory analysis of banking variables
- kNN with optimal k selection via cross-validation
- Logistic Regression with regularization tuning
- Side-by-side model comparison with confusion matrix and ROC curves
